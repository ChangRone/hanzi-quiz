# 國小國語生字資料

本目錄保存可供 `hanzi-quiz` 題庫產生流程使用的「教材生字來源資料」，不直接取代 `packs/` 題目檔。

## 固定來源

1. **主要來源**：中央研究院語言學研究所「大腦與語言實驗室」生字表字詞資料庫，固定版本 `20260723`。
2. **全量交互驗證**：雄::gsyan HTML5-FUN 各版本筆順設定資料庫（115上、114下）。
3. **人工抽驗來源**：地方爸爸與他的小幫手們。來源 PDF 僅作目視核對，不重新散布。

詳細來源、版本、URL、SHA-256：`source-manifest.json`。

## Quiz 對應

出版社代碼沿用 `config/schema-config.json`：

- `0`：南一
- `1`：翰林
- `2`：康軒

`academicYearStart + publisherCode + grade + semesterCode` 可對應既有題包教材 ID 的組成邏輯。

欄位約定：

- `term`：學期自然序號，`1=上學期`、`2=下學期`
- `semester` / `semesterCode`：沿用 Quiz 既有代碼，`0=上學期`、`1=下學期`

每課資料：

- `write`：習寫字
- `recognition`：認讀字
- `all`：依主要來源原始順序合併
- `validation.status`
  - `exact`：與第三來源內容及順序一致
  - `order_only`：字集合一致，順序不同
  - `content_diff`：至少有一個字不同，需要人工複核

來源不一致時**不會用第三來源自動覆蓋中研院資料**。

## 驗證摘要

針對中研院檔案中有明確課次的 407 課資料，與 gsyan 全量比對：

- 完全一致：379 課
- 字相同、只有順序差異：15 課
- 字內容有差異：13 課
- 字集合一致合計：394 / 407 課

另外，地方爸爸 `115上 康軒二上_一般版.pdf` 每課抽 1 字，共 12 字，涵蓋習寫字與認讀字；12 / 12 均與中研院及 gsyan 一致。

## 特殊資料

中研院原始 XLSX 有少數「課次」空白：

- 115上南一一年級：數字、魔法字群。依第三來源拆成 `specialSections`，保留 `inferred` 標記。
- 115上康軒一年級：一至十，第三來源標為 `L00`，因此資料中以 `lesson=00` 保存並標 `lessonInferred=true`。
- 114下翰林六年級：兩段課次空白資料，分別與第三來源 L10、L11 完整吻合，依此補上課次並保留 inference 記錄。

## 版權與使用

本 repo 只保存結構化生字清單、來源 metadata 與驗證結果，不重新散布「地方爸爸」PDF。其 PDF 本身標示「地方爸爸製作，禁止商用」。
