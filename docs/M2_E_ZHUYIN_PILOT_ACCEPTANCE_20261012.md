# E — 注音手寫 Feature Flag 驗收（2026-10-12）

## 已通過的 CI

- 正式 Quiz 可用資料視窗的預設 OFF 開關啟用一格獨立注音試寫區，國字作答照常進行。
- 開關在同一裝置可持久化，OFF → ON → OFF 不遺失既有 `zhuyin_write` 紀錄。
- 七個位置總是存在；正確留白位出現筆跡必須 FAIL。
- `pointercancel` 要還原被取消的部分筆跡；Chromium 實際瀏覽器測試 PASS。
- `pass/fail` 以 Event v2 記為 `tested`，`UNCERTAIN` 不當成正確或錯誤，不提升熟練度。

## 人工手寫辨識 Gate（尚未完成）

1. 在**隔離測試環境**開啟此功能；目前只對每題第一個書寫字顯示獨立試寫區，不能當作完整正式注音題型。
2. 驗測：貓、巷、一、叔（二聲與輕聲）、雨／語、園、徐、旋。檢查一／二／三符號的定位，以及一聲、輕聲和右側聲調。
3. 在實際手機／平板觸控上測試短點、拖曳、抬筆、中斷、快速重寫，檢查是否產生殘影或誤判。
4. 人工觀察正確字形、錯誤符號、空格亂畫各組筆跡，記錄是否 `PASS/FAIL/UNCERTAIN`；只有完成此真實筆跡校準，才可調整辨識門檻。
5. 核對與 `hanzi_dictation`、`context_write` 熟練度隔離，再評估逐步擴大使用，不直接啟用所有課程題型。

## 重要限制

目前的符號比對是使用中文字型光柵作為 **expected-symbol prototype**，不是已證實的學生手寫分類器。PoC v5 位置規則 PASS 不代表這個辨識模組已完成裝置校準。必須保留 `UNCERTAIN` 而非猜其他符號。

PR #6 維持 Draft，基底依賴 C / PR #5；**不得自行合併或部署**。

## 現有 E 驗收工具（已加入此分支）

- 檔案：`poc/zhuyin-handwriting-qa/index.html`，為**獨立自含程式**，不是正式網站的一部分。
- 從 GitHub 的檔案頁按 **Raw → 另存 HTML**，在 PC／觸控平板的瀏覽器直接開啟；不必登入或部署正式 Quiz。
- 九組例字：貓、巷、一、叔（二聲）、叔（輕聲）、語、園、徐、旋。
- 每個例字先選「故意寫正確」或「故意寫錯／空位亂畫」，實際在七格手寫後按「檢查注音」，記錄 PASS／FAIL／UNCERTAIN。
- 建議每個例字至少各做 3 次正確與 3 次錯誤／空格測試；在「匯出 QA 統計 JSON」匯出不含筆畫與姓名的測試結果。
- 結果用於決定下一版門檻或誤判處理；在取得樣本前，**不要把字型比對當成正式手寫辨識**。
- CI 同時執行獨立頁瀏覽器驗證，包含 9 例字、7 格、無外網請求、無寫入正式學習資料庫。
- Feature Flag `hanziQuizZhuyinPilotEnabled` 僅儲存本裝置 `localStorage`，不隨 Google Drive 偏好同步到其他裝置。
