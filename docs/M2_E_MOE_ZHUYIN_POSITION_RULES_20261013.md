# E｜注音聲調位置、學生提示與手寫判定規則（2026-10-13）

## 1. 正式來源（不得混成系統自行創造的規範）

教育部《國語注音符號手冊》「壹、四、調號說明表」：
https://language.moe.gov.tw/001/Upload/files/site_content/M0001/juyin/html_ch/index.html

- 陰平（一聲）可以省略、不標。
- 陽平（二聲 `ˊ`）、上聲（三聲 `ˇ`）、去聲（四聲 `ˋ`）的**直式調號**一律在整組字音「最後一個注音符號的右上角」。
- 輕聲 `˙` 在**整組字音上方**；橫式標注方式不同（在最前方）。
- 「上調、中調、下調」並非手冊定義的正式聲調名稱；不得顯示給學生。
- W3C《中文排版需求》5.5.3.3 說明調號會在最後符號右上角，與教育部一致：
  https://www.w3.org/TR/2026/DNOTE-clreq-20261007/

**重要界線：** 教育部提供直式注音比例參考圖、調號的相對位置與印刷範例；沒有規定所有學生在數位介面作答時必須命中本系統自訂的「上／中／下」三個輸入格。三格是 **E 專案為教學與自動判定設計的固定輔助格**，不是官方書寫評量的唯一標準。

## 2. 學生 UI（5 個可見書寫區）

- 上格／中格／下格：固定顯示淡色定位格（僅供教學）。**1 個符號放中格、2 個放上與下、3 個全寫**是專案內的教學位置規則。
- 輕聲點：整組注音上方，獨立 1 區。
- 聲調：**畫面上只顯示 1 區，固定在中格右側**（使用者 2026-10-15 核准版型），不再依符號數自動移動。這是**練習操作介面**，不等於正式直式注音的調號位置；印刷與正式標記仍以最後一個注音符號的右上角為準。不要顯示 `上調、中調、下調` 三種選項。
- 一聲或輕聲時，右側聲調區保持空白；輕聲要在上方加點。
- 「看位置範例」：可以開合，固定示範 `語 ㄩˇ`、`貓 ㄇㄠ`、`巷 ㄒㄧㄤˋ`、`叔 ㄕㄨ˙`，學生自行決定是否觀看。

## 3. 判定分離

程式先檢查字音符號的預期集合／手寫近似度，再檢查手寫格位置；非標準位置不等於發音錯誤。

| 系統結果 | 描述 | Quiz 掌握度事件 |
|---|---|---|
| `pass` | 符號及格位都能確認 | `tested=pass`（E 的 opt-in 模式） |
| `position_only` | 字形辨識均達高信心，但符號在不同格子 | **不記為 `zhuyin_write` 失敗**，提示位置再練 |
| `uncertain` | 字形辨識不確定，可能是放錯格 | **不計分**，請重新書寫 |
| `fail` | 缺字／多寫；或格位對但字形明確不符 | `tested=fail`（E 的 opt-in 模式） |

底層資料模型仍保留 `g0/g1/g2` 及 `t0/t1/t2` 位置索引以維持相容性；這**不是三個學生聲調區**，畫面只顯示動態定位的 1 區。

## 4. 獨立驗收方式

- 下載 `poc/zhuyin-handwriting-qa/index.html`，瀏覽器離線開啟，9 組例字各測「寫對」「符號對但位置錯」「符號錯」。
- 每次判定後，工具僅儲存結果摘要，不儲存原始筆跡、不使用 Quiz IndexedDB。
- 仍須由真人手寫校準字形模板及容錯閾值；本階段不能宣稱已達正式考試精準度。
- 最新 Gate：E PR #6 為 Draft，不得因 CI PASS 自動合併或部署。

## 2026-10-15：使用者確認精簡版型 v2

- JSON 權威檔案：`config/zhuyin-compact-layout-v2.json`；固定參考原始座標 625×510。
- 輕聲點 `(169,43)`；上格 `(172,163)`；中格 `(170,245)`；下格 `(168,327)`；聲調 `(255,245)`。
- 輕聲點向上移；主三格 y 差均為 82px；聲調與中格相同 y，側邊僅一段聲調說明。
- 三個字音格只顯示各自名稱，不設額外長篇說明；保留「看位置範例」可自行展開。
- 輕聲點在 `pointerdown` 即顯示，`pointerup` 沒有移動時仍保留單點筆畫；`pointercancel` 應移除取消的筆畫。
- `t0/t1/t2` 依然是底層解析用的**邏輯**位置，UI 只顯示固定中格旁的 1 個聲調書寫區，不能由此宣稱聲調已符合正式印刷位置。
- 同步更新了 Quiz PR #6 與獨立 `poc/zhuyin-handwriting-qa/index.html`，不得只更新其中一個而導致字形判定與版型預覽不一致。
- 學生真實筆跡識別準確率仍待驗收，位置正確不等於字形辨識已準確。
